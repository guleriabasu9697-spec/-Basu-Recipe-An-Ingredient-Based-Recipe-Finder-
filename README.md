# Basu Recipe: An Ingredient-Based Recipe Finder

Basu Recipe is a simple, interactive website that suggests meals using ingredients you already have. Add ingredients, choose optional filters, and browse matching recipes with cooking steps.

## Features

- Add and remove ingredients
- See recipes that match your ingredients
- View which ingredients you have and which may be missing
- Filter for vegetarian recipes or meals ready in 30 minutes
- Expand recipe cards to see cooking steps
- Try built-in sample ingredient combinations
- Responsive layout with hover effects and gentle animations

## How to run

1. Download `Recipe_Finder.html`.
2. Open the file in a modern web browser.
3. Enter ingredients one at a time, or choose a sample combination.
4. Select any filters and click **Find recipes**.
5. Expand a recipe to view its cooking steps.

No installation, account, server, or API key is required. HTML, CSS, and JavaScript are included in the same file.

## How it works

The website compares entered ingredients with a small, built-in collection of recipes. It ranks recipes by the proportion of their listed ingredients that match. This is rule-based matching; the project does not currently use a trained AI model or an external recipe service.

## Technologies

- **HTML** for the page structure
- **CSS** for layout, colors, responsive styling, hover effects, and animations
- **JavaScript** for ingredient matching, filters, and recipe interactions
